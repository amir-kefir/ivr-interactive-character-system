### [ Сценарий 1 – Регистрация пользователя ]

1. Система отображает экран входа и регистрации
2. Пользователь выбирает создание аккаунта
3. Пользователь вводит имя пользователя
4. Пользователь вводит почту
5. Пользователь вводит пароль
6. Пользователь подтверждает регистрацию
7. Система отправляет данные на backend
8. Сервер проверяет корректность введённых данных
9. Если данные корректны, сервер создаёт аккаунт
10. Если данные некорректны, система уведомляет об их неправильном вводе
11. Система уведомляет пользователя об успешной регистрации
12. Пользователь получает доступ к функционалу приложения
---

### [ Сценарий 2 – Вход в систему ]

1. Система отображает экран авторизации
2. Пользователь вводит почту
3. Пользователь вводит пароль
4. Пользователь нажимает кнопку входа
5. Система отправляет запрос на сервер
6. Сервер проверяет данные
7. Если данные верны, система открывает основное 3D-пространство
8. Если данные неверны, система уведомляет об их неправильном вводе
9. Пользователь получает доступ к функционалу приложения

---

### [ Сценарий 3 – Выбор виртуального персонажа ]

1. Пользователь входит в систему
2. Система отображает список доступных персонажей
3. Запускается Сценарий 4 - "Поиск персонажей"
4. Пользователь просматривает список
5. Пользователь выбирает персонажа
6. Система запрашивает параметры персонажа с сервера
7. Backend передаёт конфигурацию персонажа
8. Клиент загружает 3D-модель
9. Персонаж появляется в сцене
10. Пользователь получает возможность начать диалог

---

### [ Сценарий 4 – Поиск персонажей ]

1. Пользователь открывает меню поиска
2. Система отображает доступные фильтры
3. Пользователь выбирает параметры фильтрации
4. Пользователь запускает поиск
5. Backend получает параметры запроса
6. Сервер выполняет фильтрацию
7. Сервер возвращает список персонажей

---

### [ Сценарий 5 – Ввод сообщения ]

1. Пользователь выбирает персонажа
2. Система отображает интерфейс общения
3. Пользователь начинает вводить сообщение
4. Система фиксирует введённую часть сообщения
5. Система анализирует введённый текст
6. Система отправляет часть текста на backend
7. Сервер анализирует полученный текст
8. Сервер определяет эмоциональное состояние персонажа
9. Система получает определённое эмоциональное состояние
10. Персонаж отображает соответствующую анимацию
11. Пункты 3–10 повторяются до завершения ввода сообщения
12. Пользователь завершает ввод сообщения

---

### [ Сценарий 6 – Обработка и получение ответа ]

1. Пользователь завершает ввод сообщения
2. Система формирует полный промпт из введённого текста
3. Система отправляет полный промпт на backend
4. Сервер анализирует текст
5. Сервер передаёт промпт языковой модели
6. Нейросеть генерирует ответ с учётом контекста и параметров персонажа
7. Сервер передаёт сгенерированный ответ в клиент
8. Система получает ответ от сервера
9. Персонаж выводит полученную реплику
10. Система отображает соответствующую реакцию персонажа

---

### [ Сценарий 7 – Обработка чувствительного сообщения ]

1. Пользователь отправляет сообщение
2. Backend анализирует текст
3. Система выявляет чувствительный контекст
4. Активируются ограничения поведения персонажа
5. Нейросеть формирует корректный ответ
6. Ответ передаётся в клиент
7. Персонаж отображает изменённую реакцию
8. Пользователь получает безопасный ответ системы

---

### [ Сценарий 8 – Завершение диалога ]

1. Пользователь ведёт диалог  
2. Пользователь выбирает завершение общения  
3. Система фиксирует окончание диалога   
4. Персонаж прощается
5. Система сохраняет историю общения
6. Система отправляет историю на сервер
7. Система скрывает интерфейс диалога  
8. Пользователь возвращается в основное меню  

---

### [ Сценарий 9 – Сохранение истории общения ]

1. Пользователь завершает разговор
2. Система формирует журнал диалога
3. Данные отправляются на backend
4. Сервер сохраняет историю общения
5. Пользователь открывает раздел истории
6. Система запрашивает данные с сервера
7. Backend передаёт сохранённые диалоги
8. Пользователь просматривает историю общения

---

### [ Сценарий 10 – Создание виртуального персонажа ]

1. Пользователь открывает меню создания персонажа
2. Система отображает доступные пресеты моделей
3. Пользователь выбирает 3D-модель
4. Пользователь выбирает файл текстуры на своём компьютере (.png/.jpg) через диалог выбора файла
5. Пользователь настраивает параметры характера
6. Пользователь вводит описание или предысторию персонажа
7. Данные отправляются на backend
8. Сервер сохраняет персонажа
